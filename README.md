# CMC studio concept

Independent React application inspired by the reference's composition and interactions. No Thirdway bundles or media are included.

```powershell
npm install
npm run dev
```

Open http://127.0.0.1:5178 . `npm run build` builds production files; `npm test` checks loader synchronization. `npm run preview` serves the production build on5178 (stop dev first).

Read **HANDOFF.md** before continuing work: approved scope, component map, design measurements, synchronization contract, verification and remaining limitations. See **NOTICE.md** for asset provenance.

The hero is an original generated still with motion. Contact form is a local demo. Menu's unfinished destinations are placeholder anchors, not additional pages.
